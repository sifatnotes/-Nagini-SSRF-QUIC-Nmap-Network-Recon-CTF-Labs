## Learning Path

A practical progression is:

1. **Build reconnaissance fundamentals** with Nmap Zero to Recon.
2. **Strengthen network concepts** with Nagini Network Bootcamp.
3. **Practice web discovery** using Gobuster Gridlock 2.
4. **Investigate hidden hosts and virtual hosts** with Host Files Hidden VHosts and Hidden Hosts Files Hunt.
5. **Explore SSRF concepts** through SSRF Mirror Maze and Nagini Internal Fetcher.
6. **Study localhost-focused SSRF** with Nagini SSRF Localhost Under Siege.
7. **Expand into QUIC-focused reconnaissance** with QUIC Quest: Nagini Recon and Quiche Unlocked.
8. **Continue with CTF investigation** using Nagini Lab Horcrux Hunt.
9. **Finish with Midwest Root Forge** for additional root-focused practice.

## How to Use the Labs

Use these cybersecurity and CTF labs only in environments where you have explicit authorization.

Recommended workflow:

1. Read the individual lab objective and requirements.
2. Identify the target, available services, and stated scope.
3. Perform reconnaissance systematically.
4. Record hosts, ports, paths, technologies, and observations.
5. Map findings to the security concept being practiced.
6. Test only against the authorized lab environment.
7. Document the methodology and lessons learned.
